# Glossary

Terms coined in this project, one line each. The code uses the same words.

- **Exercise** — one paragraph of random words hiding the letters a to z in order, with its own a to z row, number
  and timing blank. The published worksheets call it a paragraph.
- **Target** — the word that holds the next letter to find, exactly once.
- **Filler** — a word between two targets; it never holds the next target's letter.
- **Sheet** — one page of exercises, the same element in the preview and on paper (ADR 0005).
